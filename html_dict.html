Visão Geral

Esta página reúne um dicionário com as tags HTML usadas nas páginas do projeto e também demonstra recursos pedidos no exercício, como links internos no cabeçalho e uma barra lateral com informações complementares.

Use os links do topo para navegar rapidamente entre a descrição da página, a barra lateral e a lista de tags.

Dicionário de Tags

<a>
Cria links para outras páginas, arquivos ou endereços externos.
<address>
Indica informações de contato relacionadas ao autor ou à página.
<article>
Representa blocos de conteúdo independentes, como cards de projetos e destaques.
<aside>
Guarda conteúdo complementar ao conteúdo principal, como a barra lateral.
<body>
Contém todo o conteúdo visível da página.
<code>
Marca trechos de código ou texto com semântica de terminal.
<dd>
Apresenta a descrição associada a um termo em uma lista de definição.
<div>
Agrupa elementos para organizar layout, grades e áreas visuais.
<dl>
Agrupa um conjunto de termos e descrições em formato de dicionário.
<dt>
Define o termo ou a chave de uma lista de definição.
<footer>
Representa o rodapé da página ou de uma seção com conteúdo complementar.
<h1>
Marca o título principal da página.
<h2>
Marca subtítulos que organizam as seções do conteúdo.
<head>
Reúne metadados e referências usadas para configurar o documento.
<header>
Representa o cabeçalho introdutório de uma página ou seção.
<html>
Elemento raiz que envolve todo o documento HTML.
<img>
Insere uma imagem no documento, como a foto usada na barra lateral.
<li>
Define cada item de uma lista.
<link>
Relaciona o documento a um recurso externo, como a folha de estilos.
<main>
Indica o conteúdo principal da página.
<meta>
Define metadados, como codificação de caracteres e configuração responsiva.
<nav>
Delimita uma área de navegação com links importantes do site.
<p>
Representa um parágrafo de texto.
<pre>
Exibe texto pré-formatado, útil para blocos no estilo terminal.
<section>
Agrupa conteúdo relacionado em blocos temáticos.
<span>
Permite marcar pequenos trechos inline para fins visuais ou estruturais.
<strong>
Dá ênfase forte a um trecho de texto, indicando maior importância.
<title>
Define o título exibido na aba do navegador.
<ul>
Cria uma lista não ordenada de itens.
